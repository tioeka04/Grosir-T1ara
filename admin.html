Kelola produk, harga, dan isi website Grosir Tiara.

Belum punya kunci akses?
  1. Buka pembuatan token GitHub.
  2. Isi nama bebas, lalu pilih masa berlaku.
  3. Di Repository access, pilih Only select repositories lalu pilih repository website ini.
  4. Di Permissions, beri Contents: Read and write dan Actions: Read and write.
  5. Klik Generate token, salin, lalu tempel di sini.

Kunci ini hanya disimpan di browser perangkat ini. Jangan bagikan ke siapa pun.
